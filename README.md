# NFT Tracker — сайт-визитка для Telegram-ботов

Одностраничный сайт: премиум трекер, бесплатный трекер, поддержка.
Чистый HTML/CSS/JS — без сборки и серверов, работает на GitHub Pages.
Адрес: **https://trackernft.lol** (до привязки DNS — `https://rubaruba22ruba-droid.github.io/Parser/`).

## Структура

```
index.html            каркас страницы (мета, защита, пустые секции) — данных здесь нет
data/site.json        ВСЯ информация: тексты, @юзернеймы ботов, цены, поддержка, примеры лотов
assets/css/style.css  стили
assets/js/app.js      рендер из site.json + анимации страницы
assets/js/sky.js      ночная сакура: ветка с цветами и живые лепестки (canvas)
assets/js/gem.js      розовый сапфир (canvas)
assets/js/vendor.js   Anime.js + Motion (урезанная сборка, ~21 КБ gzip)
assets/fonts, img     шрифт Geologica (свой), иконки, превью для Telegram
CNAME                 домен для GitHub Pages
404.html, robots.txt, sitemap.xml, site.webmanifest, .nojekyll
tools/vendor/         исходники сборки vendor.js
```

## Как менять информацию

Открой `data/site.json` (прямо на GitHub: файл → ✏️ Edit → Commit). Через 1–2 минуты сайт обновится.

| Что поменять | Где в `site.json` |
|---|---|
| Бот премиум / бесплатный | `trackers.items[].handle` (без `@`) |
| Цена премиума (сейчас 10 TON навсегда) | `trackers.items[0].priceNum`, `priceUnit`, `priceNote` |
| Короткие пункты в карточке | `trackers.items[].points` |
| Контакт поддержки | `support.handle` |
| Заголовок и текст на входе | `hero` |
| Карточки в «ленте лотов» (пример) | `feed.lots` |
| Названия в бегущей строке | `marquee` |

Ссылки на Telegram собираются автоматически: `handle` → `https://t.me/handle`.
Значение должно быть настоящим юзернеймом (латиница, цифры, `_`, 5–32 символа), иначе кнопка не покажется.
Пиши коротко — дизайн рассчитан на 2–5 слов в пункте.

## Публикация на GitHub Pages

Сейчас сайт отдаётся из ветки `main`, папка `/ (root)`:
**Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.**

> Для бесплатного GitHub репозиторий должен быть **публичным**. Поэтому в него нельзя класть токены, `.env`, сессии и базы бота — `.gitignore` это блокирует.

## Домен trackernft.lol

В репозитории всё уже подготовлено: файл `CNAME`, адреса в `index.html` и `sitemap.xml`.
Осталось прописать DNS у регистратора, где куплен домен.

### 1. DNS-записи

| Тип | Имя (Host) | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| AAAA (по желанию) | `@` | `2606:50c0:8000::153` · `2606:50c0:8001::153` · `2606:50c0:8002::153` · `2606:50c0:8003::153` |
| CNAME | `www` | `rubaruba22ruba-droid.github.io` |

Старые A/AAAA/CNAME-записи парковки регистратора удали — они конфликтуют.

### 2. Проверка в GitHub

1. **Settings → Pages**: в поле **Custom domain** должно стоять `trackernft.lol` (если пусто — впиши и нажми **Save**).
2. Подожди, пока появится **«DNS check successful»** (от 5 минут до 24 часов).
3. Поставь галочку **Enforce HTTPS** (сертификат выпускается автоматически).

### Если «не открывается»

- Почти всегда DNS ещё не обновился или остались старые A-записи.
- Cloudflare: на время выпуска сертификата ставь записи в режим **DNS only** (серое облако), потом можно включить прокси с SSL-режимом **Full**.
- Защита от захвата домена: в личных настройках GitHub → **Pages → Add a domain**, подтверди владение через TXT-запись.

## Безопасность и где лежит информация

Что сделано:

- **Строгая CSP:** разрешены только собственные файлы; инлайн-скрипты, сторонние домены и `eval` заблокированы.
- Никаких сторонних запросов, cookies и аналитики — шрифт и библиотеки лежат в репозитории.
- Контент выводится только через `textContent`; ссылки строятся лишь как `https://t.me/<проверенный handle>` — даже подменённый `site.json` не внедрит чужую ссылку или скрипт.
- Внешние ссылки с `rel="noopener noreferrer"`; страница не открывается во фрейме чужого сайта.
- В `index.html` нет ни данных, ни ключей. Вся информация — в `data/site.json`.

Важно понимать честно: GitHub Pages — статический хостинг, всё, что показано посетителю (в том числе `site.json`), по определению публично.
Поэтому здесь хранятся только публичные вещи (юзернеймы, тексты, цены). **Секреты (токены бота, API-ключи, мнемоники, `.env`) в репозиторий класть нельзя** — они остаются на сервере бота.
Заголовки HTTP (например `X-Frame-Options`) GitHub Pages менять не даёт; при желании их можно добавить через Cloudflare перед доменом.

## Дизайн, анимации и устройства

- Стиль «ночная сакура»: глубокий чёрный, розовый акцент, плотные блоки с толстыми рамками, крупный шрифт Geologica.
- Ветка с цветами и боке рисуются один раз на canvas; лепестки живут постоянно: разная глубина и размытие, ветер, кувырок, отталкиваются от курсора, ускоряются при прокрутке.
- Розовый сапфир вращается, плавает и реагирует на мышь; блики появляются, когда грань ловит свет.
- «Лента лотов» сменяет карточки, цена набегает; бегущая строка с темами ускоряется при прокрутке.
- Anime.js — вступительная анимация, счётчики, рисование галочек; Motion — появление блоков при скролле с эффектом «наводки на резкость».
- Кнопки слегка тянутся к курсору, карточки тарифов наклоняются (только мышь), сверху — полоска прогресса прокрутки.
- Учитывается `prefers-reduced-motion`; на слабых устройствах и при экономии трафика тяжёлые эффекты упрощаются автоматически.
