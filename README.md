# NFT Tracker — сайт-визитка для Telegram-ботов

Лёгкая одностраничная визитка: премиум трекер, бесплатный трекер, поддержка.
Чистый HTML/CSS/JS — без сборки и серверов, работает на GitHub Pages.
Вес первой загрузки ≈ 80 КБ (gzip).

## Структура

```
index.html            каркас страницы (мета, защита, пустые секции) — данных здесь нет
data/site.json        ВСЯ информация: тексты, @юзернеймы ботов, цены, поддержка
assets/css/style.css  стили
assets/js/app.js      рендер из site.json + анимации
assets/js/vendor.js   Anime.js + Motion (урезанная сборка, ~21 КБ gzip)
assets/fonts, img     шрифт Inter (свой), иконки, превью для Telegram
404.html, robots.txt, site.webmanifest, .nojekyll
parser-app/           прежний мини-апп «NFT Parser Pro» (перенесён из корня, не удалён)
tools/vendor/         исходники сборки vendor.js
```

## Как менять информацию

Открой `data/site.json` (прямо на GitHub: файл → ✏️ Edit → Commit). Через 1–2 минуты сайт обновится.

| Что поменять | Где в `site.json` |
|---|---|
| Бот премиум / бесплатный | `trackers[].handle` (без `@`) |
| Цена, «навсегда», скидка | `trackers[0].price` |
| Контакт поддержки | `support.handle` |
| Пункты «что входит» | `trackers[].features` |
| Заголовок и текст на входе | `hero` |

Ссылки на Telegram собираются автоматически: `handle` → `https://t.me/handle`.
Значение должно быть настоящим юзернеймом (латиница, цифры, `_`, 5–32 символа), иначе кнопка не покажется.

## Публикация на GitHub Pages

1. Репозиторий → **Settings → Pages**.
2. **Build and deployment → Source: Deploy from a branch.**
3. **Branch:** выбери ветку с сайтом (сейчас `claude/serene-wright-hhp9ln`, после слияния — `main`), папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт открывается на `https://rubaruba22ruba-droid.github.io/Parser/`.

> Для бесплатного GitHub репозиторий должен быть **публичным**. Поэтому в него нельзя класть токены, `.env`, сессии и базы бота — `.gitignore` это блокирует.

## Привязка своего домена

### 1. DNS у регистратора домена

**Вариант А — основной домен (`example.com`)**

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| AAAA (по желанию) | `@` | `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153` |
| CNAME | `www` | `rubaruba22ruba-droid.github.io` |

**Вариант Б — только поддомен (`tracker.example.com`)**

| Тип | Имя | Значение |
|---|---|---|
| CNAME | `tracker` | `rubaruba22ruba-droid.github.io` |

Старые A/AAAA-записи парковки регистратора удали — они конфликтуют.

### 2. Подключение в GitHub

1. **Settings → Pages → Custom domain** → впиши домен (`example.com`) → **Save**.
   GitHub сам создаст файл `CNAME` в корне ветки (перед следующим пушем сделай `git pull`).
2. Подожди, пока появится **«DNS check successful»** (от 5 минут до 24 часов).
3. Поставь галочку **Enforce HTTPS** (сертификат выпускается автоматически).

### 3. После привязки

Замени адрес `https://rubaruba22ruba-droid.github.io/Parser/` на новый домен в `index.html`
(строки `canonical`, `og:url`, `og:image`, `twitter:image`) — от этого зависит красивое превью ссылки в Telegram.

### Рекомендации

- **Защита от захвата домена:** в личных настройках GitHub → **Pages → Add a domain** подтверди владение через TXT-запись.
- **Cloudflare:** на время выпуска сертификата ставь записи в режим **DNS only** (серое облако), потом можно включить прокси с SSL-режимом **Full**.
- Если домен «не открывается» — почти всегда это DNS ещё не обновился или остались старые A-записи.

## Безопасность и где лежит информация

Что сделано:

- **Строгая CSP:** разрешены только собственные файлы; инлайн-скрипты, сторонние домены и `eval` заблокированы.
- Никаких сторонних запросов, cookies и аналитики — шрифты и библиотеки лежат в репозитории.
- Контент выводится только через `textContent`; ссылки строятся лишь как `https://t.me/<проверенный handle>` — даже подменённый `site.json` не внедрит чужую ссылку или скрипт.
- Внешние ссылки с `rel="noopener noreferrer"`; страница не открывается во фрейме чужого сайта.
- В `index.html` нет ни данных, ни ключей. Вся информация — в `data/site.json`.

Важно понимать честно: GitHub Pages — статический хостинг, всё, что показано посетителю (в том числе `site.json`), по определению публично.
Поэтому здесь хранятся только публичные вещи (юзернеймы, тексты, цены). **Секреты (токены бота, API-ключи, мнемоники, `.env`) в репозиторий класть нельзя** — они остаются на сервере бота.
Заголовки HTTP (например `X-Frame-Options`) GitHub Pages менять не даёт; при желании их можно добавить через Cloudflare перед доменом.

## Анимации и устройства

- Anime.js — интро-таймлайн, рисование линий, счётчик; Motion — появление при скролле, hover/press.
- Только `transform`/`opacity`, поэтому плавно и на слабых телефонах.
- Учитывается `prefers-reduced-motion`; на слабых устройствах и при экономии трафика тяжёлые эффекты отключаются автоматически.
- Эффекты курсора (свечение, 3D-наклон) включаются только там, где есть мышь.
