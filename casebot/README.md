# Drade Drop — кейсы с NFT-подарками Telegram (бот + Mini App)

Фронтенд — исходник Force Gift из архива (структура, кейсы, лента, анимация открытия), поверх него свой
чёрно-оранжевый дизайн (`webapp/css/drade.css`, шрифты Unbounded + Onest), эффекты (`webapp/js/fx.js`) и апгрейдер как на
CaseBattle с кешбек-кейсом (`webapp/js/upgrade.js`). Бэкенд написан под API этого фронтенда. Node ≥ 22.5, без npm-зависимостей.

## Структура
```
casebot/
├─ index.js       точка входа: node index.js / npm start (читает .env)
├─ main.py        запуск на хостинге для Python-ботов: качает Node.js, даёт https-ссылку
├─ server/
│  ├─ main.mjs      HTTP: API + раздача webapp, /config.js, /tonconnect-manifest.json
│  ├─ api.mjs       open-case, sell, inventory, init-withdraw, upgrade, daily-case/*, ton/*, рефералы
│  ├─ bot.mjs       /start → «Приветствую», баннер, кнопка «Играть», закреп; оплата Stars; админ-команды
│  ├─ ton.mjs       пополнение TON: TonConnect-платёж с комментарием-меткой + ручной перевод «dep<id>»
│  ├─ fair.mjs      честная игра: бросок = HMAC-SHA256(server_seed, "client_seed:nonce"), смена и раскрытие сидов
│  ├─ odds.mjs      шансы кейсов: «fair» (RTP 49,9%) или «juicy»
│  ├─ wallet.mjs    баланс ⭐, депозиты (без дублей), 10% рефереру, депозит за окно для вывода
│  ├─ auth.mjs      проверка подписи Telegram initData
│  ├─ catalog.mjs   кейсы в формате фронтенда
│  ├─ gifts.json    каталог (генерится)   cases.json  кейсы и шансы (генерится)
│  └─ config.mjs    настройки из .env
├─ webapp/          index.html, css/, js/, fonts/, images/gifts (реальные 3D-иконки), images/cases (обложки)
└─ tools/
   ├─ gifts-raw.txt все 122 подарка с floor (TON); «?» — нет листингов, стоит оценка
   ├─ images.py     скриншоты → вырезка → апскейл x4 (Real-ESRGAN) → прозрачный WebP
   ├─ build.mjs     каталог + составы и цены кейсов (шансы считает server/odds.mjs)
   ├─ case_burst.py обложки кейсов: «взрыв» из настоящих 3D-подарков кейса со световыми шлейфами
   └─ case_art.py   обложки (через case_burst.py), баннер и аватарка бота
```

## Суть
- Валюта — ⭐ (1 TON = 100 ⭐). Пополнение: TON на `UQCvGGYFcqrPS3h_AXiVzVHvmUTKLJJ5DurV_VBhpMXcQtd3` (TonConnect или вручную с комментарием `dep<id>`) или Telegram Stars.
- 2 бесплатных кейса раз в 24 ч: сердечки по 15 ⭐ и одно NFT. Daily — с заданиями (3 шеринга + подписка на `DAILY_CHANNEL`).
- 13 платных кейсов в 4 разделах: Для разогрева 49 / 199 / 399 ⭐, Горяченькое 790 / 1 490 / 2 490 ⭐,
  Тематические (Зима 990, Хэллоуин 1 990, Бойцовский клуб 2 990, Гангста 4 990 ⭐), ALL IN 7 990 / 24 990 / 129 990 ⭐.
- Шансы (`server/odds.mjs`, модель «fair»): вероятность подарка ∝ цена^−k, k подбирается так, чтобы средний возврат
  был ровно RTP = 49,9% цены кейса; дороже кейса выпадает в 7–17% открытий. Старая модель «juicy» — переключатель в админке.
- Честная игра (`server/fair.mjs`): каждый бросок кейса, апгрейда и кешбека = первые 52 бита
  HMAC-SHA256(server_seed, `client_seed:nonce`). Игрок заранее видит sha256(server_seed), может сменить сиды — старый
  server_seed раскрывается, и любой бросок проверяется в мини-аппе (Профиль → «Правила и честная игра», там же правила
  и политика конфиденциальности). Бросок, nonce и хэш пишутся в `opens`.
- Апгрейдер (как CaseBattle): ставка 1–6 подарков → цель → шанс = ставка/цель × 0,499 (до 75%), «⚡ Быстро» — короткая крутка.
  Стрелка встаёт ровно в `roll`; звук как у ленты кейса. При сливе падает кешбек-кейс (настоящий 3D-подарок-коробка):
  в среднем `cashbackRate` = 8% ставки — обычно 2–8%, иногда до 30%, редко до 100%; от 300 ⭐ — NFT-подарок близкой цены.
- Алмазная зона апгрейда (`server/diamond.mjs`, анимация — `webapp/js/diamond.js`, `webapp/css/diamond.css`): маленький сектор
  внизу колеса. Стрелка в алмазе → колесо «леденеет», летят осколки → сцена «Алмазный дроп»: 3D-барабан перебирает NFT
  в 1,5–4 раза дороже цели и встаёт на выигрыше. Пул — все NFT в этом диапазоне, шанс каждого ∝ 1/цена; какой выпал — по
  положению броска внутри алмаза (проверяется так же, как остальное). `diamondShare` = 20% выдачи апгрейда уходит в алмаз,
  зелёная зона на столько же меньше — RTP апгрейда остаётся 49,9% (на x2 алмаз ≈ 2% круга, на x5 ≈ 1%).
  «💎 Тест алмаза» на экране апгрейда — только для админа: его апгрейды встают в алмаз (в истории помечены `admin-test`).
- Открытие x2–x5: короткие ленты (48 карточек), без спиннеров/теней/blur на каждой карточке — плавно на слабых телефонах.
- Вывод подарков: до `withdrawFreeMax` = 600 ⭐ — заявка сразу, без депозита; дороже — депозит ≥ 50 TON за 7 дней.
  Заявка приходит админам в бот с кнопками «✅ Выдал» / «❌ Отклонить» (отклонённый подарок возвращается в инвентарь),
  подарок отправляет поддержка @RelayerDrade вручную.
- **Админка** (`/admin.html`, кнопка Admin в профиле для `ADMIN_IDS`): модель шансов (fair / juicy), свои проценты (RTP, кешбек, порог вывода без депозита, доля «дороже кейса», доля крупных, нижняя граница проигрыша, мусор,
  лимит на один подарок, шанс апгрейда, реферальный %, условия вывода, курс), цены и ручные шансы каждого кейса, вкл/выкл кейсов,
  юзеры (баланс себе/любому, бан), заявки на вывод, промокоды (⭐ сразу или +% к пополнению), рассылка.
- Бот: `/start` → «Приветствую…» с баннером и кнопкой «Играть» (Mini App), сообщение закрепляется в чате (старое открепляется);
  кнопка меню «Играть», имя и аватарка (`webapp/images/avatar.jpg`) ставятся сами; канал `DAILY_CHANNEL` — подписка для Daily:
  `SUB_CHECK=click` (по умолчанию) засчитывает её, когда игрок нажал «перейти в канал»; `SUB_CHECK=real` — настоящая проверка
  (бот — админ канала, пустые аватарка и описание канала заполняются сами). `/support`, оплата Stars,
  админ-команды `/stats /wd /done /reject /give /ban /ton`.
- Пополнение TON: «Оплатить в Tonkeeper» открывает Tonkeeper с готовым переводом (адрес, сумма, комментарий),
  в любом другом кошельке — те же данные с кнопками «копировать». Переводы ищутся через toncenter v3 → tonapi →
  toncenter v2 (архивные ноды), комментарий разбирается и из BOC. Зачисление — по метке заявки, по адресу подключённого кошелька (если кошелёк потерял комментарий) или `dep<id>`;
  зачисляется фактически пришедшая сумма, игроку приходит сообщение; неопознанный перевод — админу с готовой `/give`.

## Картинки подарков
Только реальные 3D-рендеры. `tools/images.py` режет их со скриншотов (маркет Telegram «Купить подарок» → tggifts → RubUP),
увеличивает x4 нейросетью Real-ESRGAN и убирает фон. Подарок без картинки в игру не попадает.
Сейчас есть 101 из 128. Ждут картинку: Surge Boards, Desk Calendars, Light Swords, Moon Pendants, Clover Pins, Cookie Hearts,
Faith Amulets, Liberty Figures, Money Pots, Pretty Posies, Restless Jars, Snoop Doggs, Star Notepads, Stellar Rockets, Swag Bags,
Winter Wreaths, Easter Eggs, Happy Brownies, Lol Pops, Lunar Snakes, B-Day Candles, Bow Ties, Candy Canes, Chill Flames,
Holiday Drinks, Ice Creams, Jester Hats.

Цены: `tools/gifts-raw.txt` — свежий floor tggifts; для «no listings» — цена маркета Telegram ⭐ / 81 (средний курс по подаркам,
где известны обе цены) или прошлый floor. Это оценки — сверьте перед запуском (Plush Pepe ≈ 7 800 TON, Algorithm Cups ≈ 2 000 TON).

## Запуск
Один процесс: бот + Mini App на одном адресе. Node ≥ 22.5, `npm install` не нужен. Точка входа — `index.js`
(сам читает `.env`, на Node 22.5–22.12 сам включает `--experimental-sqlite`).

**Любой хостинг с Node 22 и https-доменом:** залить папку `casebot` (без `tools/`), положить `.env`
(`BOT_TOKEN`, `ADMIN_IDS`; пример — ниже), запустить `npm start` или `node index.js`. Адрес Mini App берётся сам на
Render / Railway / Koyeb / Fly / Replit / Glitch, иначе — `WEBAPP_URL=https://домен` в `.env`.
```
BOT_TOKEN=123456:ABC...
ADMIN_IDS=7595917205
TON_ADDRESS=UQCvGGYFcqrPS3h_AXiVzVHvmUTKLJJ5DurV_VBhpMXcQtd3
SUPPORT=@RelayerDrade
BRAND="Drade Drop"
# WEBAPP_URL=https://домен   — если хостинг не подставляет адрес сам
```
**Хостинг для Python-ботов (h1cloud и т. п.):** залить файлы в папку бота и запустить `python3 main.py`
(или выбрать его файлом запуска). `main.py` сам скачает Node.js 22, при пустом `WEBAPP_URL` поднимет бесплатную
https-ссылку Cloudflare (trycloudflare.com) и перезапустит процесс, если тот упадёт. Ссылка меняется при каждом
перезапуске — бот сам обновляет кнопку «Играть» в меню и в закреплённых приветствиях.
**Render:** New → Blueprint → этот репозиторий (`casebot/render.yaml`), задать `BOT_TOKEN`.
**Docker:** `docker build -t drade casebot && docker run -p 8080:8080 -v drade:/data -e BOT_TOKEN=... -e WEBAPP_URL=https://... drade`.
Локально без Telegram: `npm run dev`.

Пересборка после правки цен/кейсов: `npm run build` (`node tools/build.mjs && python3 tools/case_art.py`).
Демо-превью без сервера: `node tools/demo.mjs <папка>`.
